## О себе — Искусство и креатив

**Автор:** Филимонова Ксения, группа 932401

## Что реализовано

- Ввод имени пользователя через `prompt` и вывод приветствия через `alert`
- Массив температур в дни мероприятий: `[12, 24, 8, 31, 19, 5, 27]`
- Функция `findHottestDay` — поиск максимальной температуры
- Функция `filterWarmDays` — фильтрация тёплых дней (температура > 20 °C)
- Функция `calculateAverageTemp` — подсчёт средней температуры
- Цикл `for` для поиска холодных дней (≤ 10 °C) и вычисления их средней температуры
- Вывод результатов в `console.log` (количество холодных дней и их средняя температура)
- Условная конструкция `if` для вывода совета при жаре (≥ 30 °C)
- Функция `pluralDays` — правильное склонение слова «день» (1 день, 3 дня, 5 дней)
- Подключение внешнего скрипта через `<script src="script.js"></script>`
